# LIFEOS

A polished, mobile-friendly hackathon prototype for a South African career-development and skills-intelligence platform.

## What’s included

- Onboarding flow for a user profile
- Professional profile editor
- Skills + readiness scoring
- Career opportunities with search/filtering
- Save/unsave and application tracking
- Career dashboard and progression planning
- Local persistence through browser localStorage

## Run it locally

Open `index.html` directly in a browser.

If you want a simple local server:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Notes

This is a front-end demo prototype designed for a hackathon presentation and rapid concept validation. It is not a production authentication or database-backed application.
